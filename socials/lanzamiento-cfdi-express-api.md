---

## Cómo usar este pack

1. Genera la imagen de cada red con **Gemini** (gemini.google.com) pegando el prompt de la sección **Media**.
2. Publica con el **Texto** sugerido, adaptándolo a tu tono si hace falta.
3. **Imagen hero del blog**: usa el prompt de más abajo para generar la imagen del frontmatter del post y súbela a `videos.acromatico.dev` (las demás imágenes se usan directo en cada red).
4. El video tutorial es nuestro mejor CTA para el público de IA/developers — compártelo en las publicaciones donde aplique.
